# Computer Network Engineering Lab Guide

## Steps to Run Packet Tracer Files

1. **Download the required file**  
   - Get the `.pkt` file provided for the experiment.

2. **Open in Cisco Packet Tracer**  
   - Launch your Packet Tracer software.  
   - Open the `.pkt` file directly.

3. **Wait before testing connectivity**  
   - Allow a few seconds for devices to initialize.  
   - This ensures proper IP configuration and ARP table setup.

4. **Ping between PCs**  
   - Use the `ping` command from one PC to another.  
   - Verify successful communication across the network.

---

### Notes
- Always check interface initialization (e.g., `Gig0/0`) before testing.  
- If ping fails, troubleshoot cabling, IP addressing, and router configurations.  
- Save your work frequently to avoid losing progress.
- well there is no chance of failure
